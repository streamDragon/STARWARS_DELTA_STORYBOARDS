2D CAMERA FIRST

CURRENT-only framing guidance for CUTSCENE_SCRIPT_V1. V3/V5 remain backend implementation.
SOURCE RULE
THIS GUIDE DOES NOT DEFINE CHARACTER IDENTITY OR DIALOGUE CAST.
Dialogue is separate and closed-world. Any dialogue participant must come only from the verified EMOTIONAL_DIALOGUE_CURRENT repertoire. Do not infer dialogue characters from this guide, the Director, the Visual Atlas, filenames, display names or general Actor handles.
CAMERA DEFINES THE FRAME
Story claim→Framing→FG / MG / BG→X / Y→Screen fraction→Motion→Visible payoff
Wide
Environment dominates. Important subjects may be small.
Medium
Principal subject becomes clearly readable while geography remains.
Close / Detail
Use only when the story needs detail, reaction or impact readability.
SCREEN FRACTION, NOT RAW UNITY SCALE
screenX = 0.22
screenY = 0.55
screenWidthFraction = 0.18
0.03-0.08
Tiny distant contact.
0.10-0.20
Wide readable subject.
0.25-0.45
Principal medium / close.
A huge ship can still occupy 5% of frame width when the story needs cosmic distance. Asset size and on-screen importance are different things.
LEGAL 2D / 2.5D MOTION
screen X/Y travel
foreground / midground / background layering
scale change for approach / retreat
parallax
Hold / Push / Pull
Follow / Track / Cut
Drift / Shake / Impact Shake
orbit-like screen arc using parallax only
true 3D orbit around a flat sprite
invented Y rotation or unseen perspective
moving behind a flat sprite as if it has volume
fake depth used to hide missing visual evidence
CINEMATIC MOVE = SETUP → TRANSITION → PAYOFF
Approach
Tiny/far → grows while moving → reaches readable mark.
Pass camera
Enter → crop/overscan → exit.
Formation break
Formation readable → members diverge → post-state no longer reads intact.
Pullback reveal
Known subject → subject shrinks → hidden context becomes readable.
Retreat
Threat present → smaller/farther → visible exit and negative space.
Reaction
Cause → cut to witness → reaction changes audience understanding.
VISIBLE OBLIGATIONS
count=3 means three readable instances unless one verified grouped visual genuinely depicts three.
Attack requires readable attacker, target and visible consequence.
Destroy changes the post-state.
Travel direction remains coherent unless a turn/reset is visibly shown.
Every story claim must have visible evidence.
