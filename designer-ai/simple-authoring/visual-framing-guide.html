Correct reference

The cutscene camera is the reference frame.

Choose the shot framing first. Then decide where each visible sprite sits in the frame and how much of that frame it should occupy.

WHY THIS MATTERS

Same asset, different shot

A ship may occupy 12% of frame width in an establishing shot, 24% in a medium action shot and 42% in a threat reveal. The asset did not physically change. The camera relationship changed.

Same camera, different assets

A person, fighter and capital ship must not share one guessed transform scale. Unity measures the resolved CURRENT asset and derives scale from the requested screen occupancy.

CAMERA DEFINES THE FRAME. SCREEN FRACTION DEFINES VISUAL SIZE. REAL SPRITE BOUNDS DEFINE UNITY SCALE.

LEGAL 2D CINEMATIC LANGUAGE

Use

X/Y motion and screen direction
Foreground / midground / background sorting
Relative scale and overlap for depth impression
2D parallax and controlled screen-space arcs
Cuts, reaction cuts, reveals and silhouettes
Wide / Medium / Close / Detail framing
Hold / Push / Pull / Follow / Track / Cut
Exact CURRENT sprite, animation, VFX and UI changes

Never assume

True Z-axis geometry
A camera orbit around a flat sprite
A new perspective angle that is not in the pixels
Moving behind a sprite as if it had 3D volume
Perspective rotation invented from one flat view
Raw scale adjectives such as huge/tiny
HOW TO FAKE DEPTH WITHOUT LYING

Screen-space orbit

Move a sprite on an ellipse in X/Y around a target while keeping a legal sprite view. This is a 2D choreography, not a true camera orbit.

Parallax reveal

Move foreground faster, background slower, then pull or cut wider to expose the threat. Layer order carries the depth illusion.

Pass camera

Enter large at one edge, cross fast, overscan/crop briefly, exit. Cut to a reverse-compatible sprite if the story needs a new facing.

CINEMATIC MOVE THINKING

Do not treat a move as one lonely coordinate change. A useful move has setup -> motion -> payoff, and combines camera purpose, subject motion, staging, timing and FX/SFX when supported.

PRIMARY 60-70%
the story action
SUPPORT 20-30%
camera / reaction / escort
AMBIENT ~10%
stars / haze / small motion

Do not animate everything. Human beings discovered motion and immediately tried to apply it to every object. Resist the species instinct. Keep one clear focal idea per shot.

IF THE SHOT ONLY WORKS AFTER INVENTING 3D GEOMETRY, REDESIGN IT BEFORE JSON.

CAMERA TO SCALE

Deterministic conversion, not adjective guessing

TECHNICAL VISUAL RULE
3 / 6
1 - RESOLVE THE ACTIVE CUTSCENE CAMERA
visibleHeight = orthographicSize * 2 visibleWidth = visibleHeight * cameraAspect

1Camera first

Camera position, orthographic size, aspect ratio and shot framing establish the visible 2D rectangle.

No gameplay rectangle is required. A cutscene-only scene can be authored entirely from its own camera frame.

2 - AUTHOR WHAT THE AUDIENCE SHOULD SEE
ship.screenX = 0.22 ship.screenY = 0.55 ship.screenWidthFraction = 0.18 character.screenX = 0.72 character.screenHeightFraction = 0.25

2Screen occupancy

Debora / ChatGPT chooses normalized frame position and how much of the current shot the object should occupy. Preserve natural aspect ratio unless the contract explicitly says otherwise.

3 - UNITY MEASURES THE RESOLVED CURRENT ASSET

3Measure real asset

naturalWidth = renderer.bounds.size.x naturalHeight = renderer.bounds.size.y

4Calculate scale

desiredWorldWidth = cameraVisibleWidth * screenWidthFraction
scale = desiredWorldWidth / naturalSpriteWidth
STORY EVIDENCE PRECHECK
STORY CLAIM -> VISIBLE ELEMENTS -> ACTION / CHANGE -> CONSEQUENCE -> FINAL STATE

A fleet arrival needs a visible fleet entering/revealing. A destroyed ship needs visible target -> attack/impact -> destroyed/absent state. Dialogue alone does not prove a physical event.
SCREEN FRACTION IS AUTHORING INTENT. WORLD SCALE IS A UNITY RESULT.

WHY THIS IS LEGAL 2D

Legal

All depth comes from screen position, relative size, overlap and a cut. The hero keeps one readable travel direction through the action.

Illegal rewrite

"Camera circles behind the hero, reveals the engines, then swings around the enemy." That requires unseen geometry and new sprite views. Replace it with track + scale + cut.

SETUP -> INTERCEPT -> IMPACT. THE STORY CHANGE IS VISIBLE, NOT MERELY DESCRIBED.

FINAL 2D STORYBOARD PREFLIGHT
Every physical story claim has visible proof
Every camera subject is visible or entering/revealing
Important world evidence survives dialogue/presentation changes
Action motion is not a meaningless straight slide when cinematic motion is intended
Three consecutive shots do not repeat the exact same presentation without purpose
All composition uses screen X/Y + screen fraction
Depth is only layer order, overlap, scale and parallax
Screen direction is preserved for continuity-bearing motion
No asset view, identity or effect is invented
Simple V1 stays semantic; Unity owns backend IDs and scale
