The GOLDEN example count is derived from the active curation source's
goldenExamples[] array during export. The count is metadata for curated,
validated teaching examples; a full JSON file is included only when its
source package has passed:
1. LOAD succeeds.
2. NORMALIZE succeeds.
3. VALIDATE has no genuine red blocker.
4. BUILD EDITABLE PREVIEW succeeds.
5. A human visual check accepts the result as a good teaching example.

Schema-valid alone is not enough. Raw learning cases remain immutable evidence
and are not silently promoted into GOLDEN.
