# CASE 002 - Technically legal background, visually wrong scene

Status: REAL FAILURE / VISUAL SELECTION LESSON

Observed result:
- The JSON parsed, validated and built.
- Character animation worked.
- The selected background was technically usable as a Layer but the resulting composition did not read naturally as the intended scene.

BAD
Choose a Layer only because it is Preview-safe and its name loosely resembles the requested location.

GOOD
For a composition-defining background, also require:
- clear semantic match to the location;
- readable floor/depth/geography for the actors;
- coherent scale;
- visual-style compatibility with the character art;
- preference for a known coherent family when one exists.

LESSON
Catalog legality is necessary but not sufficient. A background can be structurally valid and still be a bad directorial choice.
