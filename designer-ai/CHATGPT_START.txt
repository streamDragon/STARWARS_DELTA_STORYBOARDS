RULES:
1. Verify OPEN_CURRENT.json has status CURRENT_VERIFIED_OPEN.
2. Treat publishTransactionId, catalogRevision, snapshotContentHash, contractRevision and schemaHash as one atomic authoring identity. Do not author if those identities disagree across CURRENT, Director View or fallback pack.
3. Start authoring from director-view/DIRECTOR_VIEW.json. It is a complete projection of the current full Catalog, not an old request-scoped candidate subset.
4. Never mix old Catalogs, remembered asset IDs, old JSON, old Instruction Books or another publish transaction.
5. Use the relevant Director category file to search Actors, Layers, Effects, UI, Animations or Audio.
6. Use exact authoringAssetId / canonicalActorAssetId / Animation assetId / Audio assetId values. Validate final JSON against catalog-contract.
7. VISUAL WORKFLOW: shortlist from Director metadata, resolve the exact asset in FULL_VISUAL_INDEX.json, then open the SINGLE CURRENT VISUAL ATLAS PDF and visually inspect the exact atlasPage and atlasSlot before making a visual claim, choosing an asset or drawing a storyboard.
8. The Visual Atlas PDF is the preferred pixel source because ChatGPT can render PDF pages directly. Individual pageImageUrl JPEG sheets remain transport/debug fallbacks only.
9. Metadata, file names, tags and displayName are never substitutes for looking at the pixels. If atlas pixels cannot be inspected, do not invent appearance.
10. Animation visuals are intentionally deduplicated. One representative image per animation family is enough to understand the action. Never request or require every frame.
11. Audio is a first-class Director input. It is non-visual and must never be treated as a visual coverage gap.
12. Prefab internals are not Director vocabulary. A safe Prefab may appear only as a CanonicalActor or PreviewSafeVisualComposite. Do not expose gameplay scripts, colliders, physics or prefab hierarchy in the cutscene plan.
13. Materials, technical textures, fonts, gameplay helpers and unsafe records are dependencies or excluded evidence, not normal creative choices.
14. VISUAL_UNAVAILABLE.json is raw Visual Library evidence only. Use director-view/completion-queue.json to decide which missing previews actually require a Unity fix.
15. A missing preview does not prove that a legitimate film asset is missing. Check director-view/eligibility-audit.json first. Entries flagged as sample/demo/generated/technical-looking require Unity source eligibility review before preview generation; GitHub does not silently delete them to improve coverage metrics.
16. If a recommendable asset lacks verified pixels, use another verified asset or clearly report the completion item. Do not guess its appearance.
17. Use the Instruction Book for cinematic lessons, BAD/GOLDEN cases and authoring invariants.
18. If direct Pages or Visual Atlas access genuinely fails, download STARWARS_DELTA_CHATGPT_DIRECTOR_CURRENT.zip from the stable URL above and continue from that same atomic snapshot.
19. Do not ask Debora to assemble packages manually. The fallback ZIP already contains the Director View, authoring contract, Instruction Book, visual indexes, representative sheets and the unified Visual Atlas PDF.
