RULES:
1. Verify OPEN_CURRENT.json has status CURRENT_VERIFIED_OPEN.
2. Treat publishTransactionId, catalogRevision, snapshotContentHash, contractRevision and schemaHash as one atomic authoring identity. Do not author if those identities disagree across CURRENT, Director View or fallback pack.
3. Start authoring from director-view/DIRECTOR_VIEW.json. It is a complete projection of the current full Catalog, not the old request-scoped 717-record candidate subset.
4. Never mix old Catalogs, remembered asset IDs, old JSON, old Instruction Books or another publish transaction.
5. Use the relevant Director category file to search Actors, Layers, Effects, UI, Animations or Audio.
6. Use exact authoringAssetId / canonicalActorAssetId / Animation assetId / Audio assetId values. Validate final JSON against catalog-contract.
7. Before making a visual claim, choosing a visual asset or drawing a storyboard, resolve its visualEvidence and inspect the actual pageImageUrl pixels.
8. Metadata, file names, tags and displayName are not substitutes for looking at the image.
9. Animation visuals are intentionally deduplicated. One representative image per animation family is enough to understand the action. Never request or require every frame.
10. Audio is a first-class Director input. It is non-visual and must never be treated as a visual coverage gap.
11. Prefab internals are not Director vocabulary. A safe Prefab may appear only as a CanonicalActor or PreviewSafeVisualComposite. Do not expose gameplay scripts, colliders, physics or prefab hierarchy in the cutscene plan.
12. Materials, technical textures, fonts, gameplay helpers and unsafe records are dependencies or excluded evidence, not normal creative choices.
13. VISUAL_UNAVAILABLE.json is raw Visual Library evidence only. Use director-view/completion-queue.json to decide which missing previews actually require a Unity fix.
14. A missing preview does not prove that a legitimate film asset is missing. Check director-view/eligibility-audit.json first. Entries flagged as sample/demo/generated/technical-looking require Unity source eligibility review before preview generation; GitHub does not silently delete them to improve coverage metrics.
15. If a recommendable asset lacks verified pixels, do not invent its appearance. Use another verified asset or clearly report the completion item.
16. Use the Instruction Book for cinematic lessons, BAD/GOLDEN cases and authoring invariants.
17. If direct Pages browsing genuinely fails, download STARWARS_DELTA_CHATGPT_DIRECTOR_CURRENT.zip from the stable URL above and continue from that same atomic snapshot.
18. Do not ask Debora to assemble packages manually. The fallback ZIP already contains the Director View, authoring contract, Instruction Book, visual indexes and representative sheets.
